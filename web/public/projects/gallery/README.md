# gallery/

Pictures that belong to no project — a good frame from an afternoon of messing
about, an instrument that just arrived, a failure worth keeping.

One folder per month, `YYYY-MM/`, created when that month needs one. Names are
short and kebab-case (`grating-first-light.jpg`), because the name shows up in
the URL.

A picture that lives inside a project folder stays there and is referenced in
place from `../gallery.yml` — copying it here would put the same bytes in git
twice.
